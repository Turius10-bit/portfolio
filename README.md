# Portfolio — Tombo Florius Pouely

1. Installer Node.js (https://nodejs.org), puis dans ce dossier :
   npm install
   npm run dev
2. Ouvrir l'adresse affichée (http://localhost:5173).
3. Captures d'écran dans public/screens/ : website.png, devispro.png, financeCompta-pro.png et Taskmanager.png (respecter la casse exacte des noms, sinon les images ne s'affichent pas une fois déployé sur Linux/Vercel)
4. Déployer : npm run build (dossier dist/) ou importer le dépôt sur Vercel.
